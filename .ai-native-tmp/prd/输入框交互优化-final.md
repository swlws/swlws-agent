## 需求背景与范围

### 背景与痛点

用户在使用输入框时，无法感知当前系统中可用的 Skill 和 MCP Server，导致已配置的能力被闲置。需要在输入框交互层提供可发现性入口。

### 功能边界

当用户在输入框中输入 `/` 时，展示一个浮层，浮层中列出当前可用的 MCP Server 和 Skill，用户可通过点击或键盘导航选择，也可通过搜索过滤缩小范围。

### 排除范围

无明确排除范围。搜索过滤、键盘导航、嵌套子菜单均在本次需求范围内。

### 与现有功能的关系

在现有 `InputBar` 组件上新增浮层交互，数据复用现有接口 `/api/mcp` 和 `/api/skills`，不修改后端逻辑。

---

## 功能说明

### 主流程

1. 用户在输入框中输入 `/`
2. 系统展示浮层，列出所有已启用的 MCP Server 和 Skill，两组之间用分割线分隔
3. 用户在浮层搜索框中输入关键词，浮层实时过滤 MCP/Skill 名称
4. 用户点击某项（或通过键盘导航选中后按 Enter）
5. 系统将对应命令填入输入框，浮层关闭

### 异常与边界路径

| 场景 | 处理方式 |
|------|---------|
| MCP 和 Skill 列表均为空 | 浮层仍展示，内容区显示空状态（无列表项） |
| 输入 `/` 后继续输入字符 | 以 `/` 后的字符作为关键词，实时过滤浮层中的 MCP/Skill 列表 |
| 按 Esc 键 | 浮层关闭，输入框内容不变 |
| 点击浮层外部区域 | 浮层关闭，输入框内容不变 |
| 选中某项后 | 命令填入输入框，浮层关闭 |

### 状态流转

```
输入 /          → 浮层展开（显示全量 MCP + Skill）
继续输入字符    → 浮层过滤（按关键词匹配）
选中项          → 命令填入输入框 + 浮层关闭
按 Esc          → 浮层关闭
点击浮层外部    → 浮层关闭
```

---

## 技术指标与接口

- MCP 列表：复用现有接口 `GET /api/mcp`，返回 `McpServerStatus[]`
- Skill 列表：复用现有接口 `GET /api/skills`，返回 `SkillMeta[]`，展示 `enabled: true` 的项
- 无需新增 API，无持久化，无 LLM 调用

---

## 验收标准

### 正向 case

- 输入框内容为空时输入 `/`，浮层出现，展示所有已启用的 MCP Server 和 Skill，两者之间有分割线
- 在 `/` 后继续输入关键词，浮层实时过滤，只显示名称包含关键词的项
- 点击浮层中某项，对应命令填入输入框，浮层关闭
- 键盘方向键可在浮层列表中移动焦点，Enter 键选中当前项

### 异常 case

- MCP 和 Skill 均为空时，输入 `/` 浮层仍展示，内容区为空（不隐藏浮层）
- 浮层展示时按 Esc，浮层关闭，输入框内容保留 `/`
- 浮层展示时点击输入框外部，浮层关闭
